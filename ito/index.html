伊都への恋文｜自由英作文

2024～2026年度の自由英作文（第4問・第5問）を，独自の採点基準に基づいて試験的に添削します。答案はテキスト入力・写真・PDFに対応します。氏名などの個人情報は入力・撮影しないでください。

このページの使い方

  1. 年度・問題を選びます。
  2. 答案を入力します。
  3. 「ChatGPTで添削する」を押します。
    問題文・採点基準・入力した答案データがコピーされ，ChatGPTが開きます。
  4. ChatGPTの入力欄に貼り付けて送信します。

手書き答案の場合

2.で「手書き答案（写真・スキャンPDF）」を選び，3. 4. の後でChatGPTに答案の写真またはスキャンPDFを添付します。

問題を読む

あなたの答案

手書き答案は，写真・スキャンPDFのまま添削できます。

  1. 下の「写真・スキャンPDFをChatGPTで添削する」を押します。
  2. ChatGPTが開いたら，答案の写真またはスキャンPDFを添付します。
  3. コピーされた指示文を貼り付けて送信します。

氏名・学校名・受験番号などの個人情報は写さないでください。

文字データ入りPDFを使う場合

文字データを含むPDFは，ここから答案欄へ取り込めます。画像だけのスキャンPDFや手書き写真は，上の「写真・スキャンPDFをChatGPTで添削する」を使ってください。

PDFを開いています…
読み取っています…（数十秒かかることがあります）
0 語

語数は空白区切りで機械的に数えています（記号だけのものは数えません。ハイフンでつないだ語や「67%」は1語）。

採点しています…（採点基準との照合に1〜2分かかることがあります）
