# より抜き図書館｜内容減点の境界事例：GPT-6単回レビュー（2026-11-10）

## 1．実施条件と限界

- 対象：現行`main`の`sum/index.html`の採点指示，および`buncan/index.html`の2025年度文学部の原文全文。
- 入力素材：`tests/yorinuki-content-boundary-cases.md`にあるB1～B6，C1～C4の10答案。全て「日本文要約・120字以内・40点満点」で共通。
- 評価者：このGitHub修正相談の**同一会話中のGPT-6による１回の内容評価**。独立した別セッションの推論でも，Webページから実際にChatGPTを起動した自動採点でも，複数回の反復採点でもない。
- **独立性の制約：**評価者は元のClaude監査とテスト素材の期待方向を知っている。盲検でなく，採点の安定性を測定する証拠ではない。
- 日本文の字数は変更後の`countJapaneseChars`と同じ方法（NFC正規化後，空白文字以外）で機械的に照合。句読点を含む。
- 事前評価の採点ポイント：C1=マインド・ワンダリングは脳の欠陥ではなく思考の本来的特徴（20点），C2=継続的な集中を要する作業では有害になりうる（10点），C3=発想の偶然の結びつきから創造性・問題解決に役立つ（10点）。全答案の共通部分は３点を再現するよう修正済み。
- 語数・字数超過W=0，日本文なので英語減点E=0・引用減点Q=0。内容の重複計算は`C=min(M,max(L,P)+D)`に従う。L=同じ原因によるポイント失点，P=原文にない内容・矛盾の割合減点，D=独立した別の失点。
- 表の数値は**１回の暫定判断**。特にB3とC4の25％減点は見解が分かれうるため，後日の独立反復の判定基準として固定しない。

## 3．今回明らかになったこと／未検証のこと

### テキストから確認できること

- B3・B4・C3はいずれも原文にない教育政策への言及を含むが，その断定の強さと筆者への帰属が異なる。
- C4は，本文の`perhaps`に相当する留保を`常に`という強い断定へ変更する。原文の立場をより断定的にしている。
- B5は運転時に重大な事故が起きうるという本文に明示された内容と矛盾する。
- B2・C1・C2には「本文にない一文がある」だけで自動的に25％を引く根拠はない。
- 字数は全答案で120字以内となり，**今回のケース間の得点差は字数減点とは独立**している。

### 確認できないこと

- ChatGPTがWebページの完全な採点用プロンプトを用いて，同じ点数を実際に出力するか。
- 25％適用の判断が独立セッションや別のモデルで安定するか。
- この10ケースが未知の要約答案へ一般化できるか。

## 4．次の独立反復検証の設計

- まずB3・B4・C2・C3・C4の５件を優先し，**１件につき独立した新規ChatGPTセッション３回**を目標とする（15回分）。可能ならB1・B2・B5・B6・C1も１件ずつ確認する。
- 各回の原文・設問・答案・配点・UI選択条件は固定し，試行ごとの前回結果や事前期待点を提示しない。
- 記録列：試行ID，モデル，入力プロンプトの同一性，字数，L，P，D，C，W，最終点，25％適用理由（または非適用理由），評価が不安定だった表現。
- 25％適用の比較は得点だけでなく，**B3とC3の筆者への誤帰属の扱い**，**B2とC4の可能性表現の強さ**を対比して判断する。
- 独立反復で実際に判定の揺れが確認された場合に限り，追加する指示文の必要性・副作用を検討する。25％・50％の率や固定15点規則は現段階で変更しない。
