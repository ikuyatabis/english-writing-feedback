# 柴田答案ラボ

Shibata Writing Lab｜入試英作文の添削ツール

大学入試の自由英作文・英文要約を学習するためのGitHub Pages版Webサイトです。大学別の採点基準と答案をまとめた添削用プロンプトを作成し，生徒自身のChatGPTへ渡して添削を受けます。

## ページ構成

トップページ（`index.html`）から，次の3ページへ進めます。

| ディレクトリ | ページ名 | 対象 |
| --- | --- | --- |
| `ito/` | 伊都への恋文 | 九州大学の自由英作文 |
| `buncan/` | 待ってろ文キャン | 早稲田大学 文学部・文化構想学部の英文要約 |
| `mita/` | 三田キャンへの道 | 慶應義塾大学 経済学部の自由英作文 |

## 使い方

事前に，生徒自身のChatGPTアカウントでログインしてください。

1. トップページから大学を選び，各ページで年度・問題または学部を選びます。
2. 答案を入力します。
3. 「ChatGPTを開く」を押します。採点基準と答案をまとめた添削用プロンプト（採点用データ）が自動でコピーされ，ChatGPTが開きます。
4. ChatGPTの入力欄に貼り付けて送信し，添削結果を確認します。

`ito/`・`mita/`で写真・PDFの答案を使う場合は，「手書き答案（写真・PDF）」を選びます。ChatGPTに採点用データを貼り付けた後，答案の写真またはPDFを添付して送信してください。写真・PDFは自動では送信されません。

本ツールのURL・QRコードや内容を，許可なくSNS等で公開・転載したり，対象者以外へ共有したりしないでください。
