# 柴田答案ラボ

Shibata Writing Lab｜入試英語の支援ツール

大学入試・英検の英語学習を支援するWebサイトです。問題・答案または構想メモと学習用の指示をまとめたデータを作成し，生徒自身のChatGPTへ渡して採点・添削や構想への助言を受けます。

## ページ構成

トップページ（`index.html`）から，次の8コンテンツと更新履歴へ進めます。

| ディレクトリ | ページ名 | 対象 |
| --- | --- | --- |
| `brain/` | ブレスト道場 | 自由英作文の構想メモ作成 |
| `misc/` | 持ち込み診療所 | 自由英作文 |
| `ito/` | 伊都への恋文 | 九州大学の自由英作文 |
| `trans/` | ことのは研究室 | 和文英訳 |
| `sum/` | より抜き図書館 | 英文の日本語・英語要約 |
| `eiken/` | 英検の庵 | 準1級・2級・準2級プラスのライティング |
| `buncan/` | 待ってろ文キャン | 早稲田大学 文学部・文化構想学部の英文要約 |
| `mita/` | 三田キャンへの道 | 慶應義塾大学 経済学部の自由英作文 |
| `history/` | 更新履歴 | 主な更新の記録と今後の予定 |

## 使い方

事前に，生徒自身のChatGPTアカウントでログインしてください。

1. トップページからコンテンツを選び，必要な年度・問題・分類・級などを指定します。
2. 各ページの案内に従い，問題・答案または構想メモを準備し，出力形式を選びます。
3. 各ページの案内に従い，生成された指示データをコピーしてChatGPTを開きます。
4. ChatGPTの入力欄に貼り付け，必要な資料を添付して送信し，採点・添削結果や構想への助言を確認します。

`ito/`・`mita/`で写真・PDFの答案を使う場合は，「手書き答案（写真・PDF）」を選びます。ChatGPTに採点用データを貼り付けた後，答案の写真またはPDFを添付して送信してください。写真・PDFは自動では送信されません。

本ツールのURL・QRコードや内容を，許可なくSNS等で公開・転載したり，対象者以外へ共有したりしないでください。
